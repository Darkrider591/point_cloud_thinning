# Point Cloud Thinning & Scaling Tool

[![Rust](https://img.shields.io/badge/rust-1.75%2B-orange.svg)](https://www.rust-lang.org/)
[![GUI](https://img.shields.io/badge/GUI-egui%20%2F%20eframe-blue.svg)](https://github.com/emilk/egui)
[![Format](https://img.shields.io/badge/formats-E57%20%7C%20LAS%20%7C%20LAZ-green.svg)]()
[![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)]()

Thin_LAS 2.1 - высокопроизводительная (при использвоании SSD) настольная утилита на языке Rust для прореживания (децимации) и масштабирования тяжелых облаков точек лазерного сканирвоания форматов E57, LAS и LAZ.

Программа решает ключевую проблему работы со сканами наземных лазерных сканеров (Leica, Faro, Trimble, Riegl и др.): многократное уменьшение объема данных без потери 2D-структуры скана и с полным 100% сохранением фотопанорам (Bubble View / RealView), при их наличии.

---

Ключевые возможности

1. Два метода прореживания (адаптивный выбор)

| Метод | Описание | Поддерживаемые форматы | Результат для САПР |
| :--- | :--- | :--- | :--- |
| По коэффициенту сетки ($k \times k$) | Целочисленная субдискретизация матрицы сканирования с шагом $k \in [2, 10]$. Лишние точки физически не пишутся в файл. | Структурированный E57 | 100% сохранение фотопанорам и структуры сетки `(RowIndex, ColumnIndex)`. Размер файла и число точек уменьшаются в $k^2$ раз (при $k=2$ в 4 раза / $-75\%$, при $k=4$ в 16 раз / $-93.8\%$). |
| По среднему расстоянию (3D-сетка вокселей) | Классическое пространственное воксельное прореживание с шагом в метрах ($0.001..=10.0$ м). В кубической ячейке сохраняется ровно одна точка. | LAS, LAZ, E57 (все типы) | Строго равномерная пространственная плотность точек по всему облаку независимо от расстояния до сканера. |

2. Полная поддержка фотопанорам (`/images2D`)
- Сохраняются все типы панорамных изображений: сферические 360°, камеры Pinhole и цилиндрические проекции.
- Изображения JPEG/PNG копируются байт-в-байт без пережатия и деградации качества.
- Идентификаторы привязки `associatedData3DGuid` динамически связываются с новыми GUID сканов: панорамы и режим вида от первого лица (Bubble View) открываются в Autodesk ReCap, Leica Cyclone, Faro Scene и CloudCompare без ошибок.

3. Масштабирование координат
- Поддержка произвольного коэффициента масштабирования ($0.001..=1000.0$).
- Автоматически масштабируются как координаты точек, так и векторы переноса в матрицах положения (`Transform` / `Pose`).

4. Адаптивный графический интерфейс (GUI)
- Быстрый и отзывчивый интерфейс на базе `eframe` / `egui`.
- Интеллектуальная адаптация под формат: при открытии файлов LAS опция децимации по сетке автоматически затемняется (disabled) с подсказкой о причине.
- Подробные всплывающие подсказки (tooltips) для каждого параметра.
- Многопоточная обработка: фоновый рабочий поток не блокирует интерфейс, отображается процент выполнения и цветной лог в реальном времени.

Быстрый старт (Запуск готового приложения)

1. Перейдите в папку [`exe/`](exe/) и запустите файл [`Thin_LAS_2.1.exe`](exe/Thin_LAS_2.1.exe).
2. Нажмите кнопку «Выбрать входной файл» и укажите файл облака точек (`.e57`, `.las` или `.laz`).
3. Нажмите кнопку «Сохранить результат» и выберите путь назначения.
4. Настройте параметры:
   - Включите «Включить прореживание» и выберите нужный способ (по коэффициенту сетки или по среднему расстоянию).
   - При необходимости включите «Включить масштабирование».
5. Нажмите «Начать обработку».

Сборка из исходного кода

Требования
- Установленный компилятор Rust (Cargo) версии 1.75 или новее. ([Установка rustup](https://rustup.rs/))
- ОС: Windows 10/11 x64.

Команды для сборки

```bash
# Клонирование репозитория
git clone https://github.com/YOUR_USERNAME/Thin_LAS_2.1.git
cd Thin_LAS_2.1

# Запуск тестов
cargo test -- --nocapture

# Сборка оптимизированной релизной версии
cargo build --release
```

Готовый бинарный файл будет создан по пути:
`target/release/Thin_LAS_2_1.exe`

Архитектура и технические детали

- Библиотека E57: используется форк [`e57`](https://crates.io/crates/e57) v0.11 с полной поддержкой работы с бинарными блобами изображений и прототипами записей.
- Битовая упаковка пакетов: поля `RowIndex` и `ColumnIndex` приведены к байт-выровненному диапазону `Integer { min: 0, max: u32::MAX }`, что исключает ошибки переполнения пакетов `logic error: packet remainder` при малом числе точек.
- Хэширование 3D-вокселей: для молниеносного пространственного прореживания используется `SeaHasher` и битовые карты `RoaringBitmap`.
