Point Cloud Tools 2.3 — высокопроизводительная настольная утилита на языке Rust для прореживания (децимации), обрезки и масштабирования тяжелых облаков точек лазерного сканирования форматов E57, LAS и LAZ.

Программа решает ключевые задачи при работе с данными лазерного сканирования:
1. Многократное уменьшение объема данных без потери 2D-структуры скана и со 100% сохранением фотопанорам (Bubble View / RealView).
2. Интерактивная 3D-обрезка с помощью Limit Box — выделение нужной зоны сканирования и отсечение лишнего окружения прямо в окне программы.
3. Мгновенная загрузка файлов через Drag & Drop.
4. Многопоточное ускорение с помощью Rayon — параллельная обработка координат, хеширования и вокселизации на всех ядрах процессора.

 Что нового в версии 2.3

 1. Интерактивный 3D-предпросмотр и обрезка (Limit Box)
- Отдельное окно 3D-визуализации по кнопке «3D Просмотр и Limit Box».
- Свободное изменение размера окна и 3D-холста по вертикали:
  - Окно открывается сразу с оптимальной комфортной высотой (580 px), при которой все элементы управления Limit Box полностью помещаются на экране без полос прокрутки.
  - 3 удобных способа регулировки высоты:
    1. Кнопки быстрых пресетов: `500` (компактный), `680` (стандартный), `850` (высокий) и `⛶ Макс` (распахнуть на весь экран).
    2. Интерактивная полоса изменения высоты (drag handle bar): расположена прямо под 3D-холстом, подсвечивается бирюзовым цветом и меняет курсор мыши на `↕`, позволяя плавно регулировать высоту перетаскиванием.
    3. Стандартное растягивание окна: перетаскивание нижней границы или углов окна egui мышью.
  - Боковая панель параметров Limit Box оснащена плавной вертикальной прокруткой (`ScrollArea`) с динамической высотой, подстраивающейся под текущий размер холста.
- Потоковая асинхронная загрузка точек (Real-Time Streaming UI):
  - Считывание точек запускается в отдельном фоновом потоке только при открытии 3D-окна или запросе плотности.
  - Первые точки появляются на 3D-холсте уже через ~80 мс — облако уплотняется в реальном времени прямо на глазах у пользователя.
  - Полностью неблокирующий интерфейс: вращение камеры, панорамирование, зум и перемещение слайдеров Limit Box доступны с первой же секунды без задержек и подвисаний.
  - Информативная плашка состояния в левом верхнем углу 3D-сцены (`⚡ Потоковая загрузка: X точек...`).
- Кнопка быстрой остановки и автоотмена:
  - Кнопка «Стоп (достаточно)» на боковой панели позволяет в любой момент остановить считывание и зафиксировать уже загруженные точки, не дожидаясь полной обработки многогигабайтного файла.
  - Автоматическая отмена фонового потока при закрытии 3D-окна (кнопка «Применить и закрыть» или крестик «X») — ресурсы процессора и накопителя освобождаются моментально.
- Мгновенный повторный предпросмотр (RAM-кэширование):
  - Считанная выборка точек сохраняется в оперативной памяти с привязкой к пути и размеру файла.
  - Повторное открытие 3D-окна происходит мгновенно (0 мс) без каких-либо повторных обращений к диску.
- Оптимизация чтения E57 и поддержка тяжелых многоскановых проектов (70+ ГБ):
  - Быстрое постраничное считывание пакетов E57 (`PagedFastReader`) и волновая потоковая загрузка (Rayon): для тяжёлых проектов E57 (десятки и сотни стоянок с фотопанорамами) приложение перешагивает промежуточные пакеты по 360°-профилю каждой стоянки без избыточной распаковки всех миллиардов записей и загружает все 100% стоянок в 8 прогрессивных волн (~300 000–400 000 валидных точек по всему объекту за ~2.5–3 секунды, первые точки появляются за ~12–70 мс).
  - Геодезическое позиционирование (Transform / Pose): автоматический пересчёт локальных габаритов каждого скана с учётом кватернионов поворота и трансляции в мировую систему координат. Камера 3D-вьювера и рамка Limit Box мгновенно охватывают весь реальный физический периметр объекта.
  - Аппаратное ускорение вычисления контрольных сумм страниц CRC-32C с использованием инструкций CPU (SSE4.2).
  - Отключение избыточных трансформаций координат и нормализации яркости при fallback-чтении для ускорения распаковки потоков.
- Быстрая равномерная выборка точек:
  - Быстрое произвольное позиционирование `$O(1)$` (`reader.seek()`) для LAS/LAZ, параллельное распределение по стоянкам для многосканового E57 и сквозное шаговое сканирование для одиночного E57. Выборка равномерно покрывает 100% физического пространства облака без локальной кластеризации в углу.
- Орбитальная камера (CAD / CloudCompare Orbit Controls):
  - Естественное вращение сцены зажатием левой кнопки мыши: поверхность облака строго следует за перемещением курсора по горизонтали и вертикали без зеркального отражения.
  - Панорамирование (сдвиг) зажатием правой/средней кнопки мыши или `Shift + ЛКМ`.
  - Зум колесиком мыши относительно фокуса сцены.
  - Быстрые пресеты проекций: «Изо», «Сверху», «Спереди», «Сбоку» и кнопка «Сброс» к исходному охвату.
- 3D-каркас Limit Box:
  - Отображение параллелепипеда с неоновыми ребрами и угловыми маркерами.
  - Настройка границ по осям X, Y, Z с помощью плавных ползунков и числового ввода с шагом в метрах.
  - Кнопка «Сбросить рамку к границам» для мгновенного возврата к исходным габаритам.
  - Статистика в реальном времени: линейные габариты ($\Delta X, \Delta Y, \Delta Z$ м), объем ($м^3$), количество и процент точек, попадающих внутрь рамки.
- Цветовые режимы:
  - Исходный RGB: сохранение и отображение реальных фотореалистичных цветов точек из файлов LAS/E57.
  - Градиент высоты Z (Rainbow / Turbo): окраска точек по высотной отметке.
- Поворот Limit Box по оси Z (XY) и инкрементальная процентная выборка (`×0.5`, `×2`, `Обновить`): при уменьшении процента выборка мгновенно прореживается в RAM, при увеличении — догружается только дельта.
- Компактная запись E57 (`f32` / `f64`): переключатель «Координаты E57 в f32 (компактный файл)» (по умолчанию включён для структурированных E57 с локальными координатами сканера и выключен для неструктурированных E57) и оптимизация диапазона `RowIndex`/`ColumnIndex` под реальные границы скана.
  - Точки вне рамки подсвечиваются полупрозрачным цветом или полностью скрываются чекбоксом «Скрывать внешние точки».
  - Встроенный 3D-компас осей координат (X: красный, Y: зеленый, Z: синий).

 2. Поддержка Drag & Drop
- Мгновенная загрузка файлов `.las`, `.laz` и `.e57` напрямую в окно программы из Проводника (< 10 мс).
- Чтение метаданных, габаритов и количества точек выполняется строго по XML/бинарным заголовкам без предварительного сканирования массива точек.
- Визуальная подсветка зоны сброса при наведении файла.
- Автоматическое определение формата, расчет числа точек, извлечение габаритов и автозаполнение имени выходного файла.

 3. Многопоточная оптимизация (Rayon)
- Пакетная параллельная обработка точек (чанками по 65 536 точек).
- Проверка Limit Box, масштабирование координат, вычисление воксельных ключей и 64-битное хеширование выполняются параллельно на всех ядрах CPU.
- Параллельная проекция точек облака при отрисовке в 3D-вьювере через `Rayon::par_iter()`.

 Основные возможности

 Способы прореживания

| Метод | Описание | Поддерживаемые форматы | Результат для САПР |
| :--- | :--- | :--- | :--- |
| По коэффициенту сетки ($k \times k$) | Целочисленная субдискретизация матрицы сканирования с шагом $k \in [2, 10]$. Лишние точки физически не пишутся в файл. | Структурированный E57 | 100% сохранение фотопанорам и структуры сетки `(RowIndex, ColumnIndex)`. Размер файла и число точек уменьшаются в $k^2$ раз (при $k=2$ в 4 раза / $-75\%$, при $k=4$ в 16 раз / $-93.8\%$). |
| По среднему расстоянию (3D-сетка вокселей) | Классическое пространственное воксельное прореживание с шагом в метрах ($0.001..=0.5$ м). В кубической ячейке сохраняется ровно одна точка. | LAS, LAZ, E57 (все типы) | Строго равномерная пространственная плотность точек по всему облаку независимо от расстояния до сканера. |

 Оценка плотности и прогноз размера файла
- Кнопка «Оценка средней плотности» для предварительного анализа облака точек по быстрой репрезентативной выборке.
- Расчёт основан на физико-геометрической модели ёмкости воксельной сетки с учётом площади поверхности объекта ($S_{\text{box}}$) и многосканерного перекрытия (точность прогноза свыше 95%).

 Полная поддержка фотопанорам (`/images2D`)
- Сохраняются все типы панорамных изображений: сферические 360°, камеры Pinhole и цилиндрические проекции.
- Изображения JPEG/PNG копируются байт-в-байт без пережатия и потери качества.
- Идентификаторы привязки `associatedData3DGuid` динамически связываются с новыми GUID сканов: панорамы и режим вида от первого лица (Bubble View) открываются в Autodesk ReCap, Leica Cyclone, Faro Scene, nanoCAD и CloudCompare без ошибок.

 Масштабирование координат
- Поддержка произвольного коэффициента масштабирования ($0.0001..=10.0$).
- Быстрые кнопки: `1:1000` (мм $\to$ м), `1:100` (см $\to$ м), `1000:1` (м $\to$ мм).
- Автоматически масштабируются координаты точек и матрицы положения сканов (`Transform` / `Pose`).
